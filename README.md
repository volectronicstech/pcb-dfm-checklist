# PCB DFM Checklist

A practical pre-fab review list for rigid, flex and metal-core PCBs.

## 1. Copper and spacing

- Minimum trace width and spacing stated in the fab drawing
- Copper-to-edge clearance at least 0.3 mm on routed edges
- Thermal relief spokes sized for the assembly method

## 2. Drill and via

- Finished hole size vs. drill size difference documented
- Aspect ratio below 10:1 for standard through-holes
- Via-in-pad filled and capped where used

## 3. Solder mask and finish

- Mask dam width at least 0.1 mm
- Surface finish matched to the assembly process
- No mask openings on test points left unspecified

## 4. Panel and breakaway

- Panel utilization checked before tooling
- V-cut depth and residual thickness specified

## 5. Documentation

- Gerber, drill and fab drawing in one archive
- Stack-up and impedance targets listed on the drawing
